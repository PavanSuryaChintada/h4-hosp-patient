## What these numbers measure

The labels were produced by the organisers' deterministic rule engine running the published reference tables on each patient's true regimen; the hidden test labels come from the same engine. Our rule engine (Phase 3) implements those same published rules. So a training score measures whether name resolution, list parsing and our implementation of the published rules are right. It does not measure whether the rules are clinically right: the labeller and the detector share them by design. Expect the test score to differ where the test lists are written differently, not where the rules differ.
